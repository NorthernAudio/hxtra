# Preset LED color (`HX_PRESET_COLOR=1`, `tools/features/preset_color.py`, `src/m4/preset_color.s`)

In Preset footswitch mode, the current preset's ring and its switch icon on the Home screen in the colour Global Settings > Displays > Preset LED Color picks. Status tags as in [conventions.md](../conventions.md).

- **The stock Preset look** [verified offline]: the LED refresh `0x28dd0b3c` switches on each footswitch's function byte (`tbb` at `0x28dd0b80`); function 13, the one Preset mode gives FS1..FS3, is the case at `0x28dd0c10`. It reads the footswitch's preset (`0x28dd5454(0x28d9607c(), k, &byte)`), the current one (`0x28df0248(0, &cur)`), and turns the ring off when they differ; when they match it sets mode 1 (`0x28db8260(k, 1)`), then the colour `[r10]` (`0x28dd0c3e`, call `0x28dd0c44`): r10 is the literal `0x28dd0f40` = `0x28e3c4a0`, the word `0x0300ff` (the palette's red), and that literal is the word's only use in Entry 0. TogglEXP (function 12) reads the same red for EXP 1 at `0x28dd0c5e` and green `0x28e3c49c` for EXP 2.
- **The Preset-mode Home builder** [verified offline]: `0x28dc712c(home, flag)` (called at `0x28dc8b1a`) writes the three presets of the bank as `bank * 3 + k` and gives icon `home + 0x3f4 + 0x24k` `Icon_SwitchRed` (0x78) for the current preset and `Icon_SwitchDark` (0x112) for the others (`mov.w r1,#0x112; it eq; moveq r1,#0x78` at `0x28dc7194`, setImage at `0x28dc71a0`). **[hypothesis]** The label builder's function-13 case `0x28dc7288` is for a footswitch whose controller is a preset select (types 0xe..0x10, Red/RedOff at `0x28dc74ae`), not Preset mode; it stays stock.
- **Setting**: Preset LED Color, virtual ID `0xe1` (container 113, bits 0..3), label `LED\nPreset` (Preset over LED: "Preset LED" is too long for a line), values Red (default) .. White, Tap LED Color's palette without Rainbow and Random. `MENU = 'Displays'`: with Tap LED Color in Displays' third slot it opens Displays' second page.
- **Hooks**: `own_call` on `0x28dd0c44` (`preset_led`) and `0x28dc71a0` (`preset_icon`, which only changes `Icon_SwitchRed`); a Home paint `chain_ptr` before-handler (`preset_paint`) that, when the setting differs from the one last applied, re-colours each footswitch with function 13 whose ring is lit (mode byte `0x281f35f8 + k` = 1, the stock lights only the current preset's), as leaving Global Settings relights no ring and rebuilds no icon. The LED colour setter `0x28db81fc` sends the colour at once to a lit ring, under its own lock.
- **Tests**: `tests/test_preset_color.py` (handlers in unicorn, the stock sites and icons, the build), `tests/test_virtual_settings.py` (a turn on Displays' second page steps it), `tools/hx_devtest.py` case `preset_color` for the unit.
